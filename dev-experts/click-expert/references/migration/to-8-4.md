# 8.3 → 8.4.x

Docs: https://github.com/pallets/click/blob/main/CHANGES.md
(8.4.0 released 2026-05-17; 8.4.1 2026-05-21; 8.4.2 2026-06-24)

## Typing (source-compatible, may fail a type check)

- `ParamType` is a **generic abstract base class** parameterized by its converted value
  type, and can no longer be instantiated directly. Write `class MyType(click.ParamType[int])`
  (`../parameters/types/custom-types.md`).
- `convert` return types are narrowed on every concrete type (`STRING` → `str`, `INT` →
  `int`, …); `to_info_dict` returns `TypedDict` subclasses instead of `dict[str, Any]`.
- `Choice` is generic over its choice type: `Choice[HashType]`, `Choice[str]`.
- `CompositeParamType` and the number-range base are generic with abstract methods.
- `Parameter` is an **abstract** base class — instantiate `Option` or `Argument`.
- `Parameter.name` is now `str`, never `None`; with `expose_value=False` it is `""`.
- `Parameter.get_error_hint`'s `ctx` is typed `Context | None`.

## `CliRunner` capture

- New `capture` parameter: `"sys"` (default) or `"fd"`. `"fd"` redirects file descriptors
  1 and 2 via `os.dup2`, capturing output from stale stream references, `logging`/
  `structlog`, C extensions and subprocesses (`../testing.md`).
- The 8.3.3 change that exposed the original fd through `fileno()` in the default mode was
  **reverted** — it broke pytest's fd-level capture teardown. C-level consumers should use
  `capture="fd"`.
- `capture="fd"` is unavailable on Windows.

## Behavior changes

- **Feature switch arbitration is source-aware** (`../parameters/value-resolution.md`): the
  most explicit source wins; within the default tier an explicit `default=` beats an
  auto-derived one; the remaining tie-break reverted from 8.3.x's first-wins back to
  **last-declared wins**.
- **`type=UNPROCESSED` is auto-detected** for a `flag_value` that is not `str`/`int`/
  `float`/`bool`, so classes and enum members pass through unchanged without declaring it
  (`../parameters/flags.md`).
- **`default_map` string values are split** for parameters with `nargs > 1` or a `Tuple`
  type, matching environment-variable behavior.
- **`version_option` resolves import names.** A `package_name` that is not a distribution
  is retried as a top-level module via `importlib.metadata.packages_distributions()`, so
  `PIL`/`Pillow` and `jwt`/`PyJWT` no longer raise `RuntimeError` (8.4.2)
  (`../parameters/shortcut-decorators.md`).
- **`NoSuchCommand`** is a new exception carrying suggestions for misspelled commands
  (`../errors-and-exit-codes.md`).
- **`click.get_pager_file`** is new; `echo_via_pager` flushes per write so generators
  stream, and neither closes a borrowed stdout (8.4.2) (`../utils/pager.md`).
- **`get_parameter_source()` works during eager callbacks and type conversion** again
  (8.4.1).
- **Error hints pick a non-shadowed help option**, so `Try '... -h'` no longer points at a
  subcommand option that shadows `-h`.
- **`wrap_text` measures visible width**, ignoring ANSI sequences.
- `os.startfile` is used for `open_url` on Windows (8.4.0), fixing paths with spaces
  (8.4.1) (`../utils/editor-and-launch.md`).
- Readline works on non-Windows prompts: prompt text is passed to readline, so backspace,
  line editing and wrapping behave.
- A `Group` with `invoke_without_command=True` renders `[COMMAND]` in the usage line
  (8.4.2) (`../help-pages.md`).
- Failed `hide_input` prompts show the type's own message with the value masked.

## Completion fixes

Zsh scripts parse on Windows (8.4.1); `Enum` values used as `Choice` complete correctly
(8.4.1); Fish handles multi-line option help — 8.4.0 broke the format, 8.4.2 fixed it by
escaping newlines and tabs. **Upgrade straight to 8.4.2 if the CLI ships Fish completion.**

## Common Anti-Patterns

- `class MyType(click.ParamType):` unparameterized in a type-checked codebase → use
  `ParamType[T]`.
- Pinning `click==8.4.0` with Fish completion → take 8.4.2.
- Relying on the first-declared option winning a switch-group tie → it is last-declared.
- Adding `type=click.UNPROCESSED` to every object-valued flag → now inferred.
