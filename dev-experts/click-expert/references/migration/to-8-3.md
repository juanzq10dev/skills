# 8.2 → 8.3.x

Docs: https://github.com/pallets/click/blob/main/CHANGES.md
(8.3.0 released 2025-09-17; 8.3.1–8.3.3 through 2026-04)

Mostly one theme: the relationship between `default`, `flag_value` and `type` was reworked
so `default` stops being silently transformed. The details that survived into 8.4 are in
`../parameters/flags.md`; this file is the delta.

## `default` is preserved

- The value passed as `default=` now reaches the function **as-is**, with one exception:
  a flag with `default=True` still resolves to its `flag_value`.
- 8.3.3 narrowed that exception to **non-boolean** flags. For a boolean flag,
  `default=True` is the literal Python `True`.
- `default` may now be any type — `bool`, `None`, anything.
- `default` may be set on an `Argument` with `nargs=-1` (`../parameters/arguments.md`).
- A callable `flag_value` is no longer instantiated when used as a default via
  `default=True` (8.3.2).
- `flag_value` with `is_flag=False` can be used without an explicit value (8.3.2).

## The `UNSET` sentinel

`Sentinel.UNSET` marks "no default was supplied", distinct from `default=None`. Across
8.3.1–8.3.3 it was made invisible to user code: it is replaced by `None` through
`Context.invoke`, hidden by `lookup_default()` and by context lookups inside parameter
callbacks, skips `type_cast_value`, and in a `default_map` is treated as **absent** so the
next source is used (`../parameters/value-resolution.md`).

You should never observe `UNSET` in a command callback. If you do, that is a bug to report,
not a value to handle.

## `ParameterSource` is an `IntEnum`

Members are reordered most- to least-explicit, so they compare:

```python
if ctx.get_parameter_source("port") < click.ParameterSource.DEFAULT_MAP:
    ...  # explicitly provided
```

## Other changes

- Pager and editor commands are split with `shlex.split` and run **without** `shell=True`
  (8.3.3), so `PAGER="less -R"` keeps its arguments (`../utils/pager.md`).
- `Context.with_resource` receives exception information on teardown.
- `make_default_short_help` is now private API.
- `show_default` as a custom string is honoured in prompts, matching help text
  (`../parameters/prompting.md`).
- 8.3.3 briefly exposed the original fd through `CliRunner`'s `fileno()`; **8.4.0 reverted
  it** (`to-8-4.md`).

## Common Anti-Patterns

- Relying on 8.2's transformation of `default` for flags → it is gone; state the value you
  want.
- Writing `if value is Sentinel.UNSET` in a callback → you will not see it.
- Adopting 8.3.3's `fileno()` behavior → reverted one release later; use `capture="fd"`.
