# 8.1 → 8.2

Docs: https://github.com/pallets/click/blob/main/CHANGES.md (released 2025-05-10)

The largest step in the 8.x line. Everything below can break working code.

## Removals and deprecations

| Old                                       | New                                                    |
| ----------------------------------------- | ------------------------------------------------------ |
| Python 3.7 / 3.8 / 3.9                    | Python >= 3.10 required                                |
| `click.__version__`                       | `importlib.metadata.version("click")`                  |
| `BaseCommand`                             | `Command` (removed in 9.0)                             |
| `MultiCommand`                            | `Group` (removed in 9.0)                               |
| `OptionParser`, the `click.parser` module | nothing — parsing is internal                          |
| `Context.protected_args`                  | `Context.args`                                         |
| `Parameter.add_to_parser`                 | nothing — no separate parser is built                  |
| `parser.split_arg_string`                 | `click.shell_completion.split_arg_string`              |
| `HelpOption`                              | gone; help-option defaults are set up by the decorator |

## Behavior changes

- **`CliRunner` streams are independent.** `mix_stderr` is **removed**. `result.stderr` is
  always collected and never raises; `result.output` is now a third stream that interleaves
  both as a terminal would, so it is no longer an alias for `result.stdout`. Tests that
  asserted on `output` and meant stdout must change (`../testing.md`).
- **`no_args_is_help` exits 2, not 0.** A group invoked with no arguments prints help and
  returns a usage exit code (`../errors-and-exit-codes.md`).
- **Command names lose trailing suffixes.** `_command`, `_cmd`, `_group`, `_grp` are
  stripped when deriving a name from the function, so `def sync_cmd()` becomes `sync`, not
  `sync-cmd` (`../quickstart.md`).
- **`Context.close` runs on exit,** so `call_on_close` callbacks and `with_resource`
  context managers now actually fire (`../commands/context.md`).
- **`envvar` + `flag_value`:** the `flag_value` is used rather than the environment
  variable's value.
- **`Option.flag_value` no longer defaults from `Option.default` when `is_flag=False`.**
- **Duplicate parameter names now emit a `UserWarning`.**
- **`ParamType` methods gained a `ctx` argument** (`get_metavar`, `get_missing_message`, …).
  Subclasses overriding them need updating (`multi-version-support.md`).
- **`deprecated` accepts a string** and can be set on options and arguments, not just
  commands; the help label moved from `(Deprecated) help` to `help (DEPRECATED)`.
- **`echo_via_pager` no longer swallows `KeyboardInterrupt`** and terminates the pager when
  the generator raises.

## Additions worth adopting

- `Choice` accepts any iterable, including `Enum` — stop mapping enums to strings by hand
  (`../parameters/types/choice.md`).
- `Choice.get_invalid_choice_message` for a custom error.
- `Option.get_help_extra` to inspect the generated help extras.
- `CliRunner(catch_exceptions=...)` as a runner-level default.
- `progressbar(hidden=True)`.
- `click.edit(filename=...)` accepts an iterable of filenames.

## Common Anti-Patterns

- `CliRunner(mix_stderr=False)` → `TypeError`; the streams are already separate.
- `assert result.output == "x\n"` when the command also writes to stderr → use
  `result.stdout`.
- Keeping `class MyGroup(click.MultiCommand)` → subclass `click.Group`.
- `try: import click; click.__version__` for a version gate → feature-detect
  (`multi-version-support.md`).
